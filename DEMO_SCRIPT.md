# Demo script

1. Open the dashboard and show the three-page AG Studio preset: Overview, Risk and Guardrails, and Case Explorer.
2. Ask the analyst agent: “Which disputes are closest to their deadline?” The agent is read-only and cannot issue payment actions.
3. Run simulated Case B. Show the conflict cap, the refund decision, and the Guardrail Activity widget.
4. Run Case C and review the approval state in the existing dispute drawer.
